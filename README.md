\# Payment Status Monitoring \& Notification System



\## Project Overview



A simple payment status monitoring application developed using Python Flask and SQLite.



Users can enter a transaction ID and check the current payment status.



\## Technologies Used



\- Python

\- Flask

\- SQLite

\- Docker

\- Git

\- GitHub

\- GitHub Actions



\## Features



\- Check payment status using Transaction ID

\- Display customer name and payment amount

\- Show payment status

\- Health check endpoint

\- Docker containerization

\- GitHub Actions CI

\- Docker monitoring



\## Payment Status



\- SUCCESS

\- PENDING

\- FAILED



\## DevOps Workflow



Developer → GitHub → GitHub Actions → Test → Docker Build → Docker Container → Health Check → Monitoring
